1. Create a simple HTML form that submits a name using GET.

Answer 1:

<!doctype html>
<form method="get" action="">
  <label>Name: <input type="text" name="name"></label>
  <button type="submit">Send</button>
</form>
<?php
if (isset($_GET["name"])) {
    echo "Hello, " . htmlspecialchars($_GET["name"], ENT_QUOTES, "UTF-8");
}
?>

Output 1:

After submitting name=Asha: Hello, Asha

Note:

Save as a .php file and open it through XAMPP at http://localhost/yourfile.php. GET values appear in the URL.

2. Receive a name from a POST form.

Answer 2:

<!doctype html>
<form method="post" action="">
  <input name="name" required>
  <button type="submit">Send</button>
</form>
<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $name = trim($_POST["name"] ?? "");
    echo "Hello, " . htmlspecialchars($name, ENT_QUOTES, "UTF-8");
}
?>

Output 2:

After submitting name=Asha: Hello, Asha

Note:

POST keeps form data out of the URL, but it is not encryption; use HTTPS for transport security.

3. Display a submitted email address after basic validation.

Answer 3:

<?php
$email = trim($_POST["email"] ?? "");
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    if (filter_var($email, FILTER_VALIDATE_EMAIL)) {
        echo "Valid email";
    } else {
        echo "Invalid email";
    }
}
?>
<form method="post">
  <input type="email" name="email" required>
  <button type="submit">Check</button>
</form>

Output 3:

Submitting student@example.com: Valid email

Note:

Use your own test input when running the form.

4. Validate that a required name is not empty.

Answer 4:

<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $name = trim($_POST["name"] ?? "");
    echo ($name === "") ? "Name is required" : "Name accepted";
}
?>
<form method="post">
  <input name="name">
  <button>Submit</button>
</form>

Output 4:

Empty submission: Name is required

6. Read a checkbox value safely.

Answer 6:

<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    if (isset($_POST["agree"])) {
        echo "Accepted";
    } else {
        echo "Please accept the terms";
    }
}
?>
<form method="post">
  <label><input type="checkbox" name="agree" value="yes"> I agree</label>
  <button>Submit</button>
</form>

Output 6:

Checked: Accepted; unchecked: Please accept the terms

7. Show how a submitted value is accessed using GET.

Answer 7:

<?php
$city = $_GET["city"] ?? "Not provided";
echo htmlspecialchars($city, ENT_QUOTES, "UTF-8");
?>

Output 7:

For URL ?city=Delhi: Delhi

Note:

Use a URL such as http://localhost/file.php?city=Delhi.

8. Explain GET versus POST with a small example.

Answer 8:

<!-- GET form -->
<form method="get"><input name="q"><button>Search</button></form>
<!-- POST form -->
<form method="post"><input name="name"><button>Submit</button></form>

Output 8:

GET: form values are appended to the URL. POST: values are sent in the request body.

Note:

GET is suitable for searches and bookmarkable filters; POST is commonly used for submissions that change data. Neither method alone provides confidentiality.

9. Validate student registration fields on the server.

Answer 9:

<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $name = trim($_POST["name"] ?? "");
    $email = trim($_POST["email"] ?? "");
    $errors = [];
    if ($name === "") $errors[] = "Name is required";
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) $errors[] = "Valid email required";
    if ($errors) {
        echo implode("<br>", $errors);
    } else {
        echo "Registration details accepted";
    }
}
?>
<form method="post">
  <input name="name" placeholder="Name">
  <input name="email" type="email" placeholder="Email">
  <button>Register</button>
</form>

Output 9:

With valid name and email: Registration details accepted

Note:

This validates fields; saving a registration requires a database insert.

10. Demonstrate a login form with server-side field validation.

Answer 10:

<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $username = trim($_POST["username"] ?? "");
    $password = $_POST["password"] ?? "";
    if ($username === "" || $password === "") {
        echo "Both fields are required";
    } else {
        echo "Fields received; verify credentials on the server";
    }
}
?>
<form method="post">
  <input name="username" required>
  <input name="password" type="password" required>
  <button>Login</button>
</form>

Output 10:

With both fields filled: Fields received; verify credentials on the server

Note:

This is field validation only, not authentication. Real authentication should query the database and use password_verify() with a stored password hash.

11. Sanitize output to help prevent HTML injection.

Answer 11:

<?php
$comment = $_POST["comment"] ?? "<b>Hello</b>";
echo htmlspecialchars($comment, ENT_QUOTES, "UTF-8");
?>

Output 11:

&lt;b&gt;Hello&lt;/b&gt;

Note:

Escape user-supplied text when displaying it in HTML.

12. Preserve a form value after submission.

Answer 12:

<?php
$name = $_POST["name"] ?? "";
?>
<form method="post">
  <input name="name" value="<?= htmlspecialchars($name, ENT_QUOTES, 'UTF-8') ?>">
  <button>Submit</button>
</form>
<?php
if ($name !== "") echo "Submitted: " . htmlspecialchars($name, ENT_QUOTES, "UTF-8");
?>

Output 12:

After submitting Asha: Submitted: Asha

Note:

The input value is escaped before being inserted into the HTML attribute.
