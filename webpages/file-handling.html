1. Write text to a file using file_put_contents().

Answer 1:

<?php
$bytes = file_put_contents("sample.txt", "Hello PHP");
echo $bytes;
?>

Output 1:

9

Note:

Creates or overwrites sample.txt in the current working directory.

2. Read the contents of a file.

Answer 2:

<?php
file_put_contents("sample.txt", "Hello PHP");
echo file_get_contents("sample.txt");
?>

Output 2:

Hello PHP

3. Append text to a file.

Answer 3:

<?php
file_put_contents("log.txt", "Start\n");
file_put_contents("log.txt", "Next\n", FILE_APPEND);
echo file_get_contents("log.txt");
?>

Output 3:

Start
Next

4. Check whether a file exists.

Answer 4:

<?php
file_put_contents("report.txt", "Ready");
echo file_exists("report.txt") ? "File exists" : "Missing";
?>

Output 4:

File exists

5. Get a file's size in bytes.

Answer 5:

<?php
file_put_contents("sample.txt", "ABC");
echo filesize("sample.txt");
?>

Output 5:

3

6. Open a file, write to it, and close it.

Answer 6:

<?php
$file = fopen("sample.txt", "w");
fwrite($file, "PHP file");
fclose($file);
echo file_get_contents("sample.txt");
?>

Output 6:

PHP file

7. Read a file line by line.

Answer 7:

<?php
file_put_contents("lines.txt", "Red\nGreen\nBlue\n");
$file = fopen("lines.txt", "r");
while (($line = fgets($file)) !== false) {
    echo trim($line) . " ";
}
fclose($file);
?>

Output 7:

Red Green Blue

8. Count the number of lines in a text file.

Answer 8:

<?php
file_put_contents("lines.txt", "one\ntwo\nthree\n");
$lines = file("lines.txt", FILE_IGNORE_NEW_LINES);
echo count($lines);
?>

Output 8:

3

9. Delete a file using unlink().

Answer 9:

<?php
file_put_contents("temporary.txt", "Remove me");
if (unlink("temporary.txt")) {
    echo "Deleted";
}
?>

Output 9:

Deleted

Note:

Only delete files that the application is authorized to remove.

10. Handle a missing file without displaying a warning.

Answer 10:

<?php
$path = "missing.txt";
if (is_readable($path)) {
    echo file_get_contents($path);
} else {
    echo "File unavailable";
}
?>

Output 10:

File unavailable

11. Read the first line with fgets().

Answer 11:

<?php
file_put_contents("sample.txt", "First line\nSecond line\n");
$file = fopen("sample.txt", "r");
echo trim(fgets($file));
fclose($file);
?>

Output 11:

First line

12. Upload a file safely at a basic level.

Answer 12:

<?php
if ($_SERVER["REQUEST_METHOD"] === "POST" && isset($_FILES["document"])) {
    $file = $_FILES["document"];
    $allowed = ["pdf", "txt"];
    $extension = strtolower(pathinfo($file["name"], PATHINFO_EXTENSION));
    if ($file["error"] !== UPLOAD_ERR_OK) {
        echo "Upload failed";
    } elseif (!in_array($extension, $allowed, true)) {
        echo "Only PDF or TXT files allowed";
    } else {
        $target = __DIR__ . "/uploads/" . uniqid("upload_", true) . "." . $extension;
        if (move_uploaded_file($file["tmp_name"], $target)) {
            echo "Upload complete";
        } else {
            echo "Could not save file";
        }
    }
}
?>
<form method="post" enctype="multipart/form-data">
  <input type="file" name="document" required>
  <button>Upload</button>
</form>

Output 12:

For an allowed upload saved successfully: Upload complete

Note:

Create the uploads directory and grant the web server write permission. Production upload handlers should also validate MIME/content, enforce size limits, and prevent execution of uploaded files.
