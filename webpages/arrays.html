1. Create and display an indexed array element.

Answer 1:

<?php
$fruits = ["Apple", "Banana", "Mango"];
echo $fruits[2];
?>

Output 1:

Mango

2. Count the elements of an array.

Answer 2:

<?php
$numbers = [10, 20, 30, 40];
echo count($numbers);
?>

Output 2:

4

3. Add an item to the end of an array.

Answer 3:

<?php
$colors = ["Red", "Blue"];
$colors[] = "Green";
echo implode(", ", $colors);
?>

Output 3:

Red, Blue, Green

4. Add an item using array_push().

Answer 4:

<?php
$items = ["Pen"];
array_push($items, "Pencil", "Eraser");
echo count($items);
?>

Output 4:

3

5. Remove and display the last item using array_pop().

Answer 5:

<?php
$numbers = [2, 4, 6];
echo array_pop($numbers) . " ";
echo count($numbers);
?>

Output 5:

6 2

6. Loop through an indexed array.

Answer 6:

<?php
$nums = [3, 6, 9];
foreach ($nums as $num) {
    echo $num . " ";
}
?>

Output 6:

3 6 9

7. Access an associative array by key.

Answer 7:

<?php
$student = ["name" => "Mira", "course" => "BCA"];
echo $student["course"];
?>

Output 7:

BCA

8. Check whether an item exists using in_array().

Answer 8:

<?php
$colors = ["Red", "Green", "Blue"];
var_dump(in_array("Green", $colors));
?>

Output 8:

bool(true)

9. Get all keys from an associative array.

Answer 9:

<?php
$data = ["name" => "Asha", "age" => 20];
echo implode(",", array_keys($data));
?>

Output 9:

name,age

10. Merge two arrays.

Answer 10:

<?php
$a = [1, 2];
$b = [3, 4];
echo implode(" ", array_merge($a, $b));
?>

Output 10:

1 2 3 4

11. Sort an array in ascending order.

Answer 11:

<?php
$nums = [8, 2, 5];
sort($nums);
echo implode(" ", $nums);
?>

Output 11:

2 5 8

12. Access an element in a multidimensional array.

Answer 12:

<?php
$students = [
    ["Asha", 80],
    ["Ravi", 92]
];
echo $students[1][0] . " " . $students[1][1];
?>

Output 12:

Ravi 92

DAISY DHIMAN BCA 4205/25 SEC A
