STRING HANDLING

Questions List

  • 1. Create and display a string.
  • 2. Access a character by its zero-based index.
  • 3. Find the length of a string.
  • 4. Convert a string to uppercase.
  • 5. Convert a string to lowercase.
  • 6. Extract part of a string using substr().
  • 7. Find the position of a word using strpos().
  • 8. Replace a word using str_replace().
  • 9. Remove surrounding whitespace using trim().
  • 10. Split a comma-separated string into an array.
  • 11. Join array elements into a string using implode().
  • 12. Format a string with sprintf().

1. Create and display a string.

Answer 1:

<?php
$message = "Welcome to PHP";
echo $message;
?>

Output 1:

Welcome to PHP

2. Access a character by its zero-based index.

Answer 2:

<?php
$text = "Hello";
echo $text[1];
?>

Output 2:

e

3. Find the length of a string.

Answer 3:

<?php
echo strlen("Backend");
?>

Output 3:

7

4. Convert a string to uppercase.

Answer 4:

<?php
echo strtoupper("php language");
?>

Output 4:

PHP LANGUAGE

5. Convert a string to lowercase.

Answer 5:

<?php
echo strtolower("HELLO PHP");
?>

Output 5:

hello php

6. Extract part of a string using substr().

Answer 6:

<?php
echo substr("Programming", 0, 7);
?>

Output 6:

Program

7. Find the position of a word using strpos().

Answer 7:

<?php
$text = "Learn PHP today";
echo strpos($text, "PHP");
?>

Output 7:

6

Note:

Positions are zero-based. Test strpos() with !== false because a match can occur at position 0.

8. Replace a word using str_replace().

Answer 8:

<?php
echo str_replace("Java", "PHP", "Learn Java now");
?>

Output 8:

Learn PHP now

9. Remove surrounding whitespace using trim().

Answer 9:

<?php
$text = "  hello  ";
echo "[" . trim($text) . "]";
?>

Output 9:

[hello]

10. Split a comma-separated string into an array.

Answer 10:

<?php
$fruits = explode(",", "apple,banana,mango");
echo $fruits[1];
?>

Output 10:

banana

11. Join array elements into a string using implode().

Answer 11:

<?php
$words = ["Backend", "Web", "Development"];
echo implode(" ", $words);
?>

Output 11:

Backend Web Development

12. Format a string with sprintf().

Answer 12:

<?php
$name = "Ravi";
$marks = 86;
echo sprintf("%s scored %d marks.", $name, $marks);
?>

Output 12:

Ravi scored 86 marks.
