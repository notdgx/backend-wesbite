1. Write a PHP program to display Hello, World!.

Answer 1:

<?php
echo "Hello, World!";
?>

Output 1:

Hello, World!

2. Display two lines using echo.

Answer 2:

<?php
echo "Backend Web Development<br>";
echo "PHP basics";
?>

Output 2:

Backend Web Development
PHP basics

Note:

In a browser, <br> creates the line break.

3. Declare a variable and display its value.

Answer 3:

<?php
$name = "Asha";
echo $name;
?>

Output 3:

Asha

4. Store a name and age, then print both in one sentence.

Answer 4:

<?php
$name = "Ravi";
$age = 20;
echo "$name is $age years old.";
?>

Output 4:

Ravi is 20 years old.

5. Show the difference between single-quoted and double-quoted strings.

Answer 5:

<?php
$name = "Mira";
echo 'Hello $name';
echo "\n";
echo "Hello $name";
?>

Output 5:

Hello $name
Hello Mira

Note:

Variable interpolation works inside double-quoted strings, not ordinary single-quoted strings.

6. Define a constant using define().

Answer 6:

<?php
define("COLLEGE", "ABC College");
echo COLLEGE;
?>

Output 6:

ABC College

7. Define a constant using const.

Answer 7:

<?php
const TAX_RATE = 0.18;
echo TAX_RATE;
?>

Output 7:

0.18

8. Display the data type of a value.

Answer 8:

<?php
$price = 49.5;
echo gettype($price);
?>

Output 8:

double

9. Check whether a variable is an integer.

Answer 9:

<?php
$count = 12;
var_dump(is_int($count));
?>

Output 9:

bool(true)

10. Convert a numeric string to an integer.

Answer 10:

<?php
$value = "25";
$number = (int) $value;
echo $number + 5;
?>

Output 10:

30

11. Join two strings using the concatenation operator.

Answer 11:

<?php
$first = "Web";
$second = "Development";
echo $first . " " . $second;
?>

Output 11:

Web Development

12. Check whether a variable exists and is not null using isset().

Answer 12:

<?php
$name = "Asha";
$city = null;
var_dump(isset($name));
var_dump(isset($city));
?>

Output 12:

bool(true)
bool(false)
