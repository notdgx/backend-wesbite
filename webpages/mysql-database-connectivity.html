1. Connect PHP to a MySQL database using MySQLi.

Answer 1:

<?php
$conn = new mysqli("localhost", "root", "", "college");
if ($conn->connect_error) {
    die("Connection failed");
}
echo "Connected successfully";
$conn->close();
?>

Output 1:

Connected successfully

Note:

XAMPP default installations commonly use localhost and root with an empty password, unless you changed these settings. Create the college database first in phpMyAdmin.

2. Create a database from PHP.

Answer 2:

<?php
$conn = new mysqli("localhost", "root", "");
if ($conn->connect_error) die("Connection failed");
$sql = "CREATE DATABASE IF NOT EXISTS college";
if ($conn->query($sql)) {
    echo "Database ready";
} else {
    echo "Database error";
}
$conn->close();
?>

Output 2:

Database ready

Note:

Run with MySQL/MariaDB started in the XAMPP Control Panel.

3. Create a students table.

Answer 3:

<?php
$conn = new mysqli("localhost", "root", "", "college");
$sql = "CREATE TABLE IF NOT EXISTS students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(150) NOT NULL
)";
if ($conn->query($sql)) echo "Table ready";
else echo "Table creation failed";
$conn->close();
?>

Output 3:

Table ready

Note:

Requires the college database to exist.

4. Insert a student using a prepared statement.

Answer 4:

<?php
$conn = new mysqli("localhost", "root", "", "college");
$stmt = $conn->prepare("INSERT INTO students (name, email) VALUES (?, ?)");
$name = "Asha";
$email = "asha@example.com";
$stmt->bind_param("ss", $name, $email);
if ($stmt->execute()) echo "Student inserted";
else echo "Insert failed";
$stmt->close();
$conn->close();
?>

Output 4:

Student inserted

Note:

Requires the students table. Running repeatedly inserts another row; use a unique constraint if duplicate emails must be prevented.

5. Retrieve and display all students.

Answer 5:

<?php
$conn = new mysqli("localhost", "root", "", "college");
$result = $conn->query("SELECT id, name, email FROM students");
while ($row = $result->fetch_assoc()) {
    echo $row["id"] . " - " . htmlspecialchars($row["name"], ENT_QUOTES, "UTF-8") . " - ";
    echo htmlspecialchars($row["email"], ENT_QUOTES, "UTF-8") . "<br>";
}
$conn->close();
?>

Output 5:

Example row: 1 - Asha - asha@example.com

Note:

Output depends on the records currently in the students table; HTML line breaks are shown as separate lines in the browser.

6. Retrieve a student by ID using a prepared statement.

Answer 6:

<?php
$conn = new mysqli("localhost", "root", "", "college");
$id = 1;
$stmt = $conn->prepare("SELECT name, email FROM students WHERE id = ?");
$stmt->bind_param("i", $id);
$stmt->execute();
$result = $stmt->get_result();
if ($row = $result->fetch_assoc()) {
    echo $row["name"] . " - " . $row["email"];
} else {
    echo "Student not found";
}
$stmt->close();
$conn->close();
?>

Output 6:

If ID 1 is Asha: Asha - asha@example.com

Note:

Requires a PHP build with MySQLi's mysqlnd driver, as included in typical XAMPP packages.

7. Update a student's email address.

Answer 7:

<?php
$conn = new mysqli("localhost", "root", "", "college");
$id = 1;
$email = "asha.new@example.com";
$stmt = $conn->prepare("UPDATE students SET email = ? WHERE id = ?");
$stmt->bind_param("si", $email, $id);
$stmt->execute();
echo ($stmt->affected_rows >= 0) ? "Update query executed" : "Update failed";
$stmt->close();
$conn->close();
?>

Output 7:

Update query executed

Note:

affected_rows may be 0 when the ID is absent or the value was already the same; inspect execute() for query success.

9. Count the number of student records.

Answer 9:

<?php
$conn = new mysqli("localhost", "root", "", "college");
$result = $conn->query("SELECT COUNT(*) AS total FROM students");
$row = $result->fetch_assoc();
echo $row["total"];
$conn->close();
?>

Output 9:

2

Note:

The example output assumes there are exactly two rows in the students table.

10. Search for students whose names match a keyword.

Answer 10:

<?php
$conn = new mysqli("localhost", "root", "", "college");
$keyword = "%Ash%";
$stmt = $conn->prepare("SELECT name FROM students WHERE name LIKE ?");
$stmt->bind_param("s", $keyword);
$stmt->execute();
$result = $stmt->get_result();
while ($row = $result->fetch_assoc()) {
    echo htmlspecialchars($row["name"], ENT_QUOTES, "UTF-8") . " ";
}
$stmt->close();
$conn->close();
?>

Output 10:

Example matching result: Asha

Note:

Results depend on the data in the table. Prepared statements help prevent SQL injection.

11. Register a user by storing a password hash.

Answer 11:

<?php
$conn = new mysqli("localhost", "root", "", "college");
$conn->query("CREATE TABLE IF NOT EXISTS users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(100) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL
)");
$username = "learner1";
$password = "examplePassword123";
$hash = password_hash($password, PASSWORD_DEFAULT);
$stmt = $conn->prepare("INSERT INTO users (username, password_hash) VALUES (?, ?)");
$stmt->bind_param("ss", $username, $hash);
if ($stmt->execute()) echo "User registered";
else echo "Registration failed";
$stmt->close();
$conn->close();
?>

Output 11:

User registered

Note:

Run once per username because username is UNIQUE. Never store plain-text passwords.

12. Check a login password using password_verify().

Answer 12:

<?php
$conn = new mysqli("localhost", "root", "", "college");
$username = "learner1";
$password = "examplePassword123";
$stmt = $conn->prepare("SELECT password_hash FROM users WHERE username = ?");
$stmt->bind_param("s", $username);
$stmt->execute();
$result = $stmt->get_result();
$row = $result->fetch_assoc();
if ($row && password_verify($password, $row["password_hash"])) {
    echo "Login successful";
} else {
    echo "Invalid username or password";
}
$stmt->close();
$conn->close();
?>

Output 12:

Login successful

Note:

Run after registering learner1 with the same password. Real applications should also use sessions, HTTPS, rate limits, and generic login errors.
