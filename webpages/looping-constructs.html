1. Print numbers 1 to 5 using for.

Answer 1:

<?php
for ($i = 1; $i <= 5; $i++) {
    echo $i . " ";
}
?>

Output 1:

1 2 3 4 5

2. Print numbers 5 to 1 using a for loop.

Answer 2:

<?php
for ($i = 5; $i >= 1; $i--) {
    echo $i . " ";
}
?>

Output 2:

5 4 3 2 1

3. Print numbers 1 to 4 using while.

Answer 3:

<?php
$i = 1;
while ($i <= 4) {
    echo $i . " ";
    $i++;
}
?>

Output 3:

1 2 3 4

4. Demonstrate a do-while loop.

Answer 4:

<?php
$i = 6;
do {
    echo $i;
    $i++;
} while ($i <= 5);
?>

Output 4:

6

Note:

A do-while loop executes its body at least once.

5. Print each item in an indexed array using foreach.

Answer 5:

<?php
$colors = ["Red", "Green", "Blue"];
foreach ($colors as $color) {
    echo $color . " ";
}
?>

Output 5:

Red Green Blue

6. Print keys and values from an associative array.

Answer 6:

<?php
$student = ["name" => "Asha", "age" => 19];
foreach ($student as $key => $value) {
    echo "$key=$value ";
}
?>

Output 6:

name=Asha age=19

7. Stop a loop with break.

Answer 7:

<?php
for ($i = 1; $i <= 5; $i++) {
    if ($i == 4) break;
    echo $i . " ";
}
?>

Output 7:

1 2 3

8. Skip one iteration using continue.

Answer 8:

<?php
for ($i = 1; $i <= 5; $i++) {
    if ($i == 3) continue;
    echo $i . " ";
}
?>

Output 8:

1 2 4 5

9. Print a 2-by-3 rectangle of stars using nested loops.

Answer 9:

<?php
for ($r = 1; $r <= 2; $r++) {
    for ($c = 1; $c <= 3; $c++) {
        echo "*";
    }
    echo "\n";
}
?>

Output 9:

***
***

10. Calculate the sum of numbers from 1 to 5.

Answer 10:

<?php
$sum = 0;
for ($i = 1; $i <= 5; $i++) {
    $sum += $i;
}
echo $sum;
?>

Output 10:

15

11. Calculate the factorial of 5 using a loop.

Answer 11:

<?php
$n = 5;
$factorial = 1;
for ($i = 1; $i <= $n; $i++) {
    $factorial *= $i;
}
echo $factorial;
?>

Output 11:

120

12. Print only even numbers from an array.

Answer 12:

<?php
$numbers = [1, 2, 3, 4, 5, 6];
foreach ($numbers as $number) {
    if ($number % 2 != 0) continue;
    echo $number . " ";
}
?>

Output 12:

2 4 6

DAISY DHIMAN BCA 4205/25 SEC A
