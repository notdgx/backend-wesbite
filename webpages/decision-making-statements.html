Questions List

  • 1. Check whether a number is positive.
  • 2. Check whether a number is even or odd.
  • 3. Find whether a number is positive, negative, or zero.
  • 4. Assign a grade using an if-elseif ladder.
  • 5. Check voting eligibility using a nested condition.
  • 6. Select a message using switch.
  • 7. Check whether a character is a vowel.
  • 8. Find the largest of two numbers.
  • 9. Find the largest of three numbers.
  • 10. Check whether a year is a leap year.
  • 11. Use a condition to print Pass or Fail.
  • 12. Check a username and password value using logical AND.

1. Check whether a number is positive.

Answer 1:

<?php
$n = 8;
if ($n > 0) {
    echo "Positive";
}
?>

Output 1:

Positive

2. Check whether a number is even or odd.

Answer 2:

<?php
$n = 7;
if ($n % 2 == 0) {
    echo "Even";
} else {
    echo "Odd";
}
?>

Output 2:

Odd

3. Find whether a number is positive, negative, or zero.

Answer 3:

<?php
$n = 0;
if ($n > 0) {
    echo "Positive";
} elseif ($n < 0) {
    echo "Negative";
} else {
    echo "Zero";
}
?>

Output 3:

Zero

4. Assign a grade using an if-elseif ladder.

Answer 4:

<?php
$marks = 76;
if ($marks >= 90) {
    echo "A";
} elseif ($marks >= 75) {
    echo "B";
} elseif ($marks >= 50) {
    echo "C";
} else {
    echo "Fail";
}
?>

Output 4:

B

5. Check voting eligibility using a nested condition.

Answer 5:

<?php
$age = 20;
$citizen = true;
if ($age >= 18) {
    if ($citizen) {
        echo "Eligible";
    } else {
        echo "Citizenship required";
    }
} else {
    echo "Too young";
}
?>

Output 5:

Eligible

6. Select a message using switch.

Answer 6:

<?php
$day = 3;
switch ($day) {
    case 1: echo "Monday"; break;
    case 2: echo "Tuesday"; break;
    case 3: echo "Wednesday"; break;
    default: echo "Unknown day";
}
?>

Output 6:

Wednesday

7. Check whether a character is a vowel.

Answer 7:

<?php
$ch = "e";
switch ($ch) {
    case "a":
    case "e":
    case "i":
    case "o":
    case "u": echo "Vowel"; break;
    default: echo "Consonant";
}
?>

Output 7:

Vowel

8. Find the largest of two numbers.

Answer 8:

<?php
$a = 18;
$b = 11;
if ($a > $b) {
    echo $a;
} else {
    echo $b;
}
?>

Output 8:

18

9. Find the largest of three numbers.

Answer 9:

<?php
$a = 4; $b = 19; $c = 12;
if ($a >= $b && $a >= $c) {
    echo $a;
} elseif ($b >= $a && $b >= $c) {
    echo $b;
} else {
    echo $c;
}
?>

Output 9:

19

10. Check whether a year is a leap year.

Answer 10:

<?php
$year = 2024;
if (($year % 400 == 0) || ($year % 4 == 0 && $year % 100 != 0)) {
    echo "Leap year";
} else {
    echo "Not a leap year";
}
?>

Output 10:

Leap year

11. Use a condition to print Pass or Fail.

Answer 11:

<?php
$marks = 39;
echo ($marks >= 40) ? "Pass" : "Fail";
?>

Output 11:

Fail

12. Check a username and password value using logical AND.

Answer 12:

<?php
$username = "admin";
$password = "php123";
if ($username === "admin" && $password === "php123") {
    echo "Details match";
} else {
    echo "Invalid details";
}
?>

Output 12:

Details match

Note:

This demonstrates conditions only; real login systems should verify password hashes stored in a database.
