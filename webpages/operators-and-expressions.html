OPERATORS AND EXPRESSIONS

Questions List

  • 2. Find the quotient and remainder of integer division.

1. Add two numbers.

Answer 1:

<?php
$a = 14;
$b = 6;
echo $a + $b;
?>

Output 1:

20

2. Find the quotient and remainder of integer division.

Answer 2:

<?php
$a = 17;
$b = 5;
echo intdiv($a, $b) . " ";
echo $a % $b;
?>

Output 2:

3 2

Note:

intdiv() is available in PHP 7 and later.

3. Calculate a number raised to a power.

Answer 3:

<?php
echo 2 ** 4;
?>

Output 3:

16

4. Use a compound assignment operator.

Answer 4:

<?php
$total = 10;
$total += 7;
echo $total;
?>

Output 4:

17

5. Compare two values using ==.

Answer 5:

<?php
var_dump(5 == "5");
?>

Output 5:

bool(true)

6. Compare two values using ===.

Answer 6:

<?php
var_dump(5 === "5");
?>

Output 6:

bool(false)

Note:

=== checks both value and data type.

7. Check whether both conditions are true using &&.

Answer 7:

<?php
$age = 22;
$hasID = true;
var_dump($age >= 18 && $hasID);
?>

Output 7:

bool(true)

8. Check whether at least one condition is true using ||.

Answer 8:

<?php
$marks = 35;
$attendance = 80;
var_dump($marks >= 40 || $attendance >= 75);
?>

Output 8:

bool(true)

9. Reverse a Boolean value using !.

Answer 9:

<?php
$isOpen = false;
var_dump(!$isOpen);
?>

Output 9:

bool(true)

10. Find the larger value using the ternary operator.

Answer 10:

<?php
$a = 9;
$b = 12;
$largest = ($a > $b) ? $a : $b;
echo $largest;
?>

Output 10:

12

11. Provide a default value using the null coalescing operator.

Answer 11:

<?php
$username = $_GET["user"] ?? "Guest";
echo $username;
?>

Output 11:

Guest

Note:

Expected output assumes the URL has no user query parameter.

12. Use the increment operator.

Answer 12:

<?php
$count = 4;
$count++;
echo $count;
?>

Output 12:

5
