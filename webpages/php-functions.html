1. Define and call a function.

Answer 1:

<?php
function greet() {
    echo "Hello";
}
greet();
?>

Output 1:

Hello

2. Pass an argument to a function.

Answer 2:

<?php
function greetUser($name) {
    echo "Hello, " . $name;
}
greetUser("Asha");
?>

Output 2:

Hello, Asha

3. Return a value from a function.

Answer 3:

<?php
function add($a, $b) {
    return $a + $b;
}
echo add(4, 7);
?>

Output 3:

11

4. Use a default parameter value.

Answer 4:

<?php
function welcome($name = "Guest") {
    echo "Welcome " . $name;
}
welcome();
?>

Output 4:

Welcome Guest

5. Return the square of a number.

Answer 5:

<?php
function square($n) {
    return $n * $n;
}
echo square(6);
?>

Output 5:

36

6. Use a type declaration for the return value.

Answer 6:

<?php
function multiply(int $a, int $b): int {
    return $a * $b;
}
echo multiply(3, 5);
?>

Output 6:

15

Note:

Requires a modern PHP version supporting scalar and return type declarations.

7. Demonstrate a local variable.

Answer 7:

<?php
function showNumber() {
    $number = 10;
    echo $number;
}
showNumber();
?>

Output 7:

10

8. Pass a variable by reference.

Answer 8:

<?php
function increase(&$n) {
    $n++;
}
$value = 4;
increase($value);
echo $value;
?>

Output 8:

5

9. Use a function to find the maximum of two numbers.

Answer 9:

<?php
function larger($a, $b) {
    return ($a > $b) ? $a : $b;
}
echo larger(7, 12);
?>

Output 9:

12

10. Calculate factorial recursively.

Answer 10:

<?php
function factorial($n) {
    if ($n <= 1) return 1;
    return $n * factorial($n - 1);
}
echo factorial(5);
?>

Output 10:

120

11. Use an anonymous function.

Answer 11:

<?php
$double = function ($n) {
    return $n * 2;
};
echo $double(9);
?>

Output 11:

18

12. Use a built-in function inside a custom function.

Answer 12:

<?php
function cleanName($name) {
    return strtoupper(trim($name));
}
echo cleanName("  mira  ");
?>

Output 12:

MIRA
